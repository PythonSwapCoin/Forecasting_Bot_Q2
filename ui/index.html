Custom forecast flow

Binary / Numeric / MCQ
  • 1) Gather input. CLI collects type, title, description, resolution, fine print.
  • 2) Build question dict. Normalised structure for downstream modules.
  • 3) Dual research. Historical & current search prompts → AskNews/Google/Perplexity summaries.
  • 4) Phase 1. Outside-view prompt family (`*_PROMPT_1`).
  • 5) Phase 2. Inside-view prompt family (`*_PROMPT_2`) with personalised context per forecaster.
  • 6) Ensemble. 5-model committee via OpenRouter with weights 1,1,1,2,2.
  • 7) Output. Text report to `custom_forecasts/` + detailed commentary.

Tournament pipeline (Metaculus)

  • 1) Intake. Pull open questions; skip if already forecasted.
  • 2) Query generation. Historical/current prompts produce search directives.
  • 3) Retrieval. AskNews, Serper (Google/News), Perplexity, custom scraping.
  • 4) Synthesis. Summaries feed outside/inside-view prompts.
  • 5) Committee. Same 5 forecasters; type-specific logic.
  • 6) Post. Optional submit/comment to Metaculus.

Polymarket benchmark

Runs 5 hardcoded binary markets through the binary pipeline and scores against frozen Polymarket probabilities.

  • Run: python custom_forecast.py --benchmark
  • Edit markets: Bot/polymarket_benchmark.py (title, description, resolution, market_probability).
  • Output: custom_forecasts/polymarket_benchmark_*.txt
  • Logged: per-forecaster probabilities, weights, final ensemble, Brier, MAE.
